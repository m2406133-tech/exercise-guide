# 얼굴 운동 가이드 메모 (손 안 대는 7가지 동물 루틴)

처음 대본을 짤 때의 설계 메모다. 지금 실제로 나오는 음성은 `대본.md`(빌드가 만듦)가 정확하다.
그 뒤 바뀐 점: 앱에서 횟수를 고를 수 있게 안내 문장에서 "서른 번" 같은 총 횟수를 뺐고,
쿼카는 두 part 대신 50회 한 번에 25회째 "입술이 풀렸으면 다시 숨기세요." 안내를 넣었고,
복어·소의 5초는 눈운동과 같이 "음성 포함 5초"가 됐다.
라마·개미핥기는 한 방향 최대 15회로 줄였다 (한 방향으로 15회 넘게 돌리면 마비감이 와서). 아래 표의 30회는 처음 설정이다.

원본: "손 터치 없이 하는 얼굴부터 목까지 얼굴 운동" 영상 자막 (0:42~13:53).
근육 설명·효과 주장·잡담은 모두 빼고 **동작 안내 + 횟수 세기**만 남겼다.

표기
- `○○ 운동.` 파일 맨 앞에 운동 이름을 말함
- `[삐]` 운동 시작/끝 신호음
- `하나 … 서른` 숫자를 소리 내어 셈. 숫자 하나 = 동작 1회. 괄호 안은 숫자 간격
- `(무음 N초)` 동작을 유지하는 시간

## 01 오리 — 입술 내밀고 위아래로 열기

오리 운동. (무음 1초)
[삐]
입술을 오리처럼 앞으로 내미세요. 그 상태로 입을 위아래로 길게 열었다 닫습니다. 옆으로 오므리지 말고, 위아래로 길게 엽니다. 숫자에 맞춰 서른 번.
(무음 2초)
하나 … 서른 (2초 간격)
입술 풀고 쉬세요. (무음 3초)

## 02 라마 — 입술로 원 그리기

라마 운동. (무음 1초)
[삐]
입술을 뽀뽀하듯 앞으로 내밀고, 입술로 크게 원을 그립니다. 한쪽 방향으로 서른 번.
(무음 2초)
하나 … 서른 (2초 간격)
반대 방향으로 서른 번.
(무음 2초)
하나 … 서른 (2초 간격)
더 안 돌아가던 쪽이 있으면, 그쪽으로 한 번 더 서른 번.
(무음 2초)
하나 … 서른 (2초 간격)
입술 풀고 쉬세요. (무음 3초)

## 03 개미핥기 — 입 안에서 혀 돌리기

개미핥기 운동. (무음 1초)
[삐]
입술을 다문 채, 입 안에서 혀로 잇몸 바깥쪽을 따라 크게 원을 그립니다. 팔자주름 자리를 지날 때 혀로 조금 더 눌러 주세요. 한쪽 방향으로 서른 번.
(무음 2초)
하나 … 서른 (2초 간격)
숨 고르세요. (무음 5초)
반대 방향으로 서른 번.
(무음 2초)
하나 … 서른 (2초 간격)
혀 풀고 쉬세요. (무음 3초)

## 04 하마 — 혀 붙이고 입 벌리기

하마 운동. (무음 1초)
[삐]
혀끝을 윗니 바로 뒤 입천장에 붙이세요. 혀를 떼지 않은 채로, 하품하듯 입을 크게 벌렸다 닫습니다. 서른 번.
(무음 2초)
하나 … 서른 (2초 간격)
입 다물고 쉬세요. (무음 3초)

## 05 복어 — 양 볼에 바람 넣기

복어 운동. (무음 1초)
[삐]
양 볼에 바람을 가득 넣고 오 초 버팁니다. 열 번. 혈압이 높은 분은 힘을 빼고 가볍게 하세요.
(무음 2초)
하나, 바람 넣고. (무음 5초) → 후, 내쉬세요. (무음 2초)
둘 … 열 (같은 패턴: 숫자 = 바람 넣기 5초, "후" = 내쉬기 2초)
쉬세요. (무음 3초)

## 06 쿼카 — 입술 숨기고 입꼬리 올리기

쿼카 운동. (무음 1초)
[삐]
입술을 안으로 말아 물어서 이를 숨기세요. 그 상태에서 광대만 써서 입꼬리를 올렸다 내립니다. 잘 안 되면 입술을 살짝 띄우고 양옆으로 벌린다고 생각하세요. 쉰 번.
(무음 2초)
하나 … 스물다섯 (2초 간격)
입술이 풀렸으면 다시 숨기세요. (무음 2초)
스물여섯 … 쉰 (2초 간격)
입술 풀고 쉬세요. (무음 3초)

## 07 소 — 목 앞쪽 늘리기

소 운동. (무음 1초)
[삐]
입술을 뽀뽀하듯 내미세요. 두 손을 모아 가슴 가운데 뼈를 누르고, 아래로 살짝 당깁니다. 그대로 고개를 앞으로 물결치듯 젖혀 목 앞쪽을 늘리고 오 초 버팁니다. 목 뒤가 아니라 목 앞쪽이 당겨야 합니다. 열 번.
(무음 2초)
하나, 누르고, 젖히고. (무음 5초) → 고개 돌아오세요. (무음 2초)
둘 … 열 (같은 패턴, 2회차부터 "돌아오고"로 짧게)
손 내리고 쉬세요. (무음 3초)

[삐]
끝.

## 정해야 할 것 (대본에서 임의로 정한 부분)
- **반복 간격 2초** — 영상엔 속도 언급이 없어 "한 번 열고 닫기/한 바퀴 = 2초"로 잡음. 빠르면 1.5초로 줄일 수 있음
- **라마 약한 쪽 한 세트** — 영상은 "한 세트 더". 소리로는 어느 쪽인지 알 수 없어 "더 안 돌아가던 쪽"으로 안내. 빼면 1분 줄어듦
- **하마 30회** — 영상은 30~50개, 아래쪽으로 잡음
- **소의 복귀 2초** — 영상에 언급 없음
- 기존 눈운동 프로젝트(`build_guide.py`)는 숫자를 서른까지만 셈 → 쿼카 50회 때문에 쉰까지 늘려야 함
