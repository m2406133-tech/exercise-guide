# 눈운동 가이드 메모

음성 대본은 `대본.md`(빌드가 만듦), 운동 내용은 `routine.json`. 빌드와 앱 사용법은 저장소 맨 위 `README.md`.

## 운동과 참고 영상
사용자가 붙여넣은 유튜브 영상 7개의 자동 자막 대본에서 눈 운동만 뽑았다(혀 운동은 제외).
영상 속 효과 주장은 음성에 넣지 않고 동작 안내만 넣었다.
04·05·13·14번은 F 영상에서 A~E 영상의 운동과 겹치지 않는 것만 골랐다. 03·09번은 G 영상에서 골랐다.

- A. 눈 요가 쇼츠 ("하루 1분만 투자하면…")
- B. 통합치의학전문의 류지헌 ("뇌를 활성화시키는 초간단 눈운동")
- C. 눈 근육 6개 쇼츠 (E의 축약본)
- D. 모양체근·수정체 운동 영상
- E. 한의사 김경 긴 영상 (눈 운동 + 혀 운동)
- F. 스포츠의학 전문가 홍정기 교수 인터뷰 (약 26분)
- G. 인제대 일산백병원 안과 이도형 교수 인터뷰 (약 18분)

| 08 | 먼 곳·중간·가까운 곳 보기 | A 0:00~0:16 | 각 30초 × 10회 (영상은 1회). 가까운 곳은 손끝("귀찮다면 손을 가까이" 반영) |
| 09 | 엄지 아주 천천히 당겼다 펴기 | G 3:23~3:51 | 당기기 6초(흐려지면 멈추고 그대로 보기) + 펴기 6초, 각각 맨 끝 1초에 "깜빡" × 10회 ("아주 천천히" → 11번 3초의 두 배로 잡음) |

| 14 | 엄지 따라가기 | F 16:54~19:07 | 30cm 엄지를 눈으로만 따라가기. 좌우·상하·사선 두 방향 각 10회, 한 방향 2.5초, 5회마다 깜빡이며 쉬기 (사선 횟수는 언급 없어 10회로) |

F에서 뺀 것: 안와 뼈 누르기(01·02와 같은 부위), 펜슬 푸시업(07·11과 같은 동작), 온열 안대 5분·50분마다 10분 쉬기(운동이 아님).
G에서 뺀 것: 눈 돌리기·상하좌우 운동(06·14와 같은 동작, 영상에서도 효과가 크지 않다고 함), 안경·선글라스·블루라이트·영양제 등(운동이 아님).
